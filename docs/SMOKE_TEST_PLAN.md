# Smoke Test Plan — local-web runtime

План ручной проверки работоспособности после установки или изменений.
Целевое время прохождения: ~10 минут + время обработки тестового файла.

Подготовка: короткий аудиофайл с речью (30–60 сек, `.mp3` или `.wav`).

| # | Шаг | Действие | Критерий прохождения |
|---|-----|----------|----------------------|
| 1 | Установка | `install.ps1` / `install.sh` | `.env` создан из шаблона; повторный запуск — шаги `skip`, конфиг не перезаписан |
| 2 | Верификация | `scripts/verify_install.*` | Все проверки `[OK]` (допустимы `[WARN]` только для опциональных компонентов) |
| 3 | Запуск | `uv run uvicorn backend.main:app --port 8001` | Сервер стартует без исключений, нет ошибок импорта |
| 4 | UI | Открыть `http://localhost:8001` | Страница отрисовывается, drop-zone и тумблер постобработки доступны |
| 5 | Config API | `GET /api/config` | `200`, в теле — `allowed_extensions` (10 форматов) и `max_file_size_gb` |
| 6 | Валидация | Загрузить файл `.txt` через UI | Понятная ошибка формата, HTTP `400`, задача не создаётся |
| 7 | Быстрый путь | Загрузить тестовый файл, постобработка **выкл** | Статусы `pending → transcribing → done`, прогресс доходит до 100, результат непустой |
| 8 | Полный путь | Загрузить тестовый файл, постобработка **вкл** | Статусы `... → processing → done`, текст отредактирован (пунктуация/абзацы) |
| 9 | Скачивание | Кнопка «Скачать .md» | Скачивается `<имя>_transcription.md` с обработанным текстом |
| 10 | Деградация | Остановить Ollama, загрузить файл с постобработкой | Задача завершается `status=error` с понятным сообщением, сервер не падает |
| 11 | Cleanup | Проверить `temp/` после задач | Временные файлы удалены; `GET /api/status/{id}` для старых задач после TTL — `404` |
| 12 | Docker | `docker compose up --build`, повторить шаги 4–9 | Те же критерии внутри контейнеров |
